# Daily Report Skill

当被要求写日报/周报时，按以下步骤：

1. 用 `agentwork goal list` 拉取平台任务列表（或使用提供给你的任务摘要）。
2. 按四节结构成文：**本周完成 / 进行中 / 下周计划 / 风险**，每节至少一条。
3. 事实性内容必须来自任务记录，标注来源（任务标题即可）；拿不准的写（待确认）。
4. 输出 Markdown，首行为 `# 日报 <日期>`，保存为调用方指定的路径。

不要编造进展；信息不足时在「风险」节说明缺口。
